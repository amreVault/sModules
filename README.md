# sModules

Модули для юзербота [Heroku](https://github.com/coddrago/Heroku) (форк Hikka).

## Установка

Установить модуль можно прямо в Telegram, указав ссылку на **raw**-файл из этого репозитория:

```
.dlm https://raw.githubusercontent.com/amreVault/sModules/refs/heads/main/sautoreact.py
```


## 📦 Модули

### sAutoReact

Авто-реакции на сообщения по триггеру в тексте или на все сообщения конкретного пользователя. Поддерживает премиум-эмодзи и несколько реакций на один триггер/юзера одновременно.

| Команда | Описание |
|---|---|
| `.saron <триггер> <emoji>` | Добавить авто-реакцию на триггер (можно несколько эмодзи на один триггер) |
| `.saroff <триггер>` | Убрать все авто-реакции с триггера |
| `.saruser <реплай/упоминание/юзернейм> <emoji>` | Авто-реакция на все сообщения пользователя |
| `.saruseroff <реплай/упоминание/юзернейм>` | Убрать все авто-реакции с пользователя |
| `.sarlist` | Список всех триггеров и пользователей с авто-реакциями |

**Как задать премиум-эмодзи:** просто вставь его прямо в сообщение с командой — модуль сам определит `document_id`. Обычные эмодзи проверяются на возможность использования как реакции.

---

### sGetID

Быстрый способ узнать ID пользователя, чата или премиум-эмодзи.

| Команда | Описание |
|---|---|
| `.suserid <реплай/упоминание/юзернейм>` | ID, имя и username пользователя |
| `.schatid` | ID текущего чата (обычный и в формате `-100...` для API) |
| `.semojiid <premium emoji>` | ID вставленного премиум-эмодзи (поддерживает несколько сразу) |
